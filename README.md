This repository serves as the remote data host for the Minecraft Aqua Launcher. It exclusively contains the JSON configuration files that supply the launcher with its active modpacks and server lists via raw GitHub Content links.

Important Note: This is not the main application.

If you are looking for the actual launcher, its source code, or the latest releases, please visit the primary project repository here:

Main Launcher Repository: https://github.com/yamanist0/minecraft-aqua-launcher
